# Лабораторная работа: Циклы с ветвлениями

## Автор
Платонова Софья (Вариант 22)

## Цель
Освоение цикла for и условных операторов if и else if на примере расчёта коэффициента сопротивления течению жидкости в шероховатой трубе.

## Описание
Программа вычисляет параметр K и коэффициент сопротивления ζ для шести заданных скоростей.

Используемые формулы:

ε = e / r
K = lg(v* · e / ν)

При K < 0,55:
ζ = 1 / (0,7 + 2K − 2lg(ε))²

При K > 0,55:
ζ = 1 / (1,18 + 1,13K − 2lg(ε))²

Здесь lg — десятичный логарифм.

Для K = 0,55 формула в условии не задана, поэтому программа выводит Undefined. Для заданных скоростей этот случай не возникает.

## Исходные данные
- Вязкость жидкости ν: 0,009 см²/с.
- Высота шероховатости e: 1 мм, в коде — 0,1 см.
- Радиус трубы r: 15 см.
- Динамические скорости v*: 0,1; 0,2; 0,5; 1; 2; 5 см/с.

Данные заданы в программе. Ввод с клавиатуры не требуется.
